# Elizabeth Ewudiwa - Digital Business Card

A modern, interactive digital business card featuring a dynamic blue and orange gradient design.

- Responsive design with modern animations
- Interactive elements and hover effects

- Direct phone call links
- Elegant gradient background
- Mobile-friendly layout

## Technologies Used

- CSS3 (with animations)
- JavaScript
- PHP (for local development server)
